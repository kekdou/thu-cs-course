## 写在前面

最终得分只有 lab1 得分 94.4/100，原因是忘记贴上和 ai 对话链接，其他均为满分  

邓公的课堂还是很令人怀念的，或许没有网传的贵系必吃那么神，但也不至于是必赤那么神  
课堂算法部分很难说对初学者友好，邓公总是不喜欢讲具体的实现，喜欢用各种各样的抽象例子和奇怪小故事来描述，或许这就是名师大家的讲课风格吧，不过很难说哪种风格更让人接受 qwq

不过邓公还是很让人敬佩的，故事还算有趣，印象很深的一点是讲到 splay tree 时提了一句学校里一个乐队取名的故事，说 splay tree 是最具有生命力的，后面发现是月之暗面的杨植麟...

值得一提的是，lab 会比 pa 麻烦很多，尽管有的 pa 确实有点难度
